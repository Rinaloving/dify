### 关键教训

1. **空数组字段用 `"[]"` 不是 `"{}"`** — `FileInfo` 是 `List<FileControlsModel>` 类型，反序列化时 `{}` 会报错
2. **文件路径存本地完整路径** — `Process` 方法用 `FileHelper.FileToStream(filePath)` 读文件，需要本地路径不是 URL
3. **复用现有 API** — 切片查询复用 `weaviateChunk/helper/api` 的 `getList`，不重复造轮子
4. **Drawer 详情页样式规范**（用户修改后学到）：
   - `wrapClassName` + `:deep()` 让内容区撑满高度
   - `.doc-detail-body` 用 `flex-direction: column` + 渐变背景
   - `.chunk-panel` 独立面板容器，`flex: 1` + `min-height`
   - 配色用蓝紫渐变（`#667eea` 系列），不是纯灰
   - `justify-content: space-between` section-title 两端对齐
5. **Vue placeholder 绑定** — 动态值用 `:placeholder="template"` 而不是 `placeholder="{{ variable }}"`
6. **批量替换用 PowerShell** — `[System.IO.File]::ReadAllText` + regex `-replace` + `WriteAllText`，不用 edit 工具逐个改
