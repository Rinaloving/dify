### 踩坑记录（重要！）
1. **JNPF JSON 大小写问题**：JNPF 默认 PascalCase 序列化（ClassName, TextKey），前端需用 `item.ClassName || item.className` 双重兼容
2. **JNPF 分页参数命名**：基类 `PageInputBase` 的属性是 `currentPage`（不是 `page`）、`pageSize`、`keyword`（小写）
3. **JNPF 分页响应格式**：返回 `{ list, total, currentPage, pageSize }`（小写），不是 `{ List, Total }`
4. **JNPF 配置注册**：必须用 `services.AddConfigurableOptions<T>()` 而不是 `services.Configure<T>()`
5. **Weaviate 认证方式**：Bearer Token（ApiKey）优先于 Basic Auth（UserName/Password）
6. **WeaviateOptions 配置**：Host 字段不带协议前缀（只填 IP），`GetUrl()` 方法拼接完整 URL
7. **前端表格组件**：BasicTable + useTable 的 api 函数参数格式需匹配，原生 a-table 更可控
