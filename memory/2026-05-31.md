# 2026-05-31 Daily Notes - Part 2

## RAG 平台功能完善

### 1. 对话历史 + 多轮对话
- 后端：`AiConversationService`（List/Detail/Delete）+ `RagChatStream` 改造（自动建会话/续写/存消息）
- 前端：左侧对话列表侧边栏，支持新建/切换/删除对话
- 多轮上下文：发送消息时带 `conversationId`，后端加载历史消息构建 LLM 上下文
- 修复：DTO 属性大小写问题（PascalCase → lowercase），输入框清空问题，双机器人头像问题

### 2. 文档重新切片
- 后端：`POST /api/rb/AiDocumentProcess/ReProcess`（自动从文档获取 datasetId，复用 Process 逻辑）
- 前端：文档列表已处理显示「重新切片」按钮，未处理显示「处理」按钮

### 3. 对话引用原文跳转
- 前端：参考来源卡片加「查看原文」按钮，点击获取文档详情 → 新窗口打开文件

### 4. 知识库检索测试
- 后端：`POST /api/rb/AiDocumentProcess/TestRetrieval`（向量化问题 → Weaviate 检索 → 返回结果）
- 前端：知识库列表加「检索测试」弹窗，输入问题 + TopK → 显示检索到的切片和相似度

### 5. 知识库权限管理
- 新建表：`ai_dataset_permission`（f_id, f_dataset_id, f_role_id, f_creator_time, f_creator_user_id）
- 后端：`AiDatasetService` 新增 `SetPermission`/`GetPermissions`/`GetAllRoles` 接口
- 权限逻辑：没配置权限 = 所有人可访问；配置了权限 = 只有被勾选的角色可访问
- 列表和下拉都按角色过滤
- 前端：知识库列表加「权限」按钮 + 角色多选弹窗
