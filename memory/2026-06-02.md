## SSE 回调参数顺序 bug（14:00-14:30）
- **现象**：bot 回答 undefinedundefined，sources 不显示
- **根因**：agChatStream 调用时 onRerank 放在 onToken 前面，导致参数错位
  - api.ts 调 onToken(token) → 实际执行 onRerank
  - api.ts 调 onDone() → 实际执行 onToken(undefined) → content += undefined = \"undefined\"
  - onDone() 被调两次 → \"undefinedundefined\"
- **修复**：把 onRerank 移到 onError 后面（第 7 个参数）
- **教训**：SSE 回调参数顺序必须与函数签名严格一致，新增可选参数放最后

## 关键教训
- SSE 回调参数顺序必须与函数签名严格一致，新增可选参数放最后
- GraphQL 查询必须包含 _additional { id }，否则对象 ID 为空
- DashScope Rerank API 不走兼容模式，用 /api/v1/services/rerank/text-reranking/text-reranking
- Weaviate Aggregate 查询无过滤条件时不加空括号，有逗号时 TrimEnd
- PostgreSQL UTF-8 不接受空字节，用 SanitizeText() 清理
- NPOI .NET Core 版本不含 HWPF，只有 .NET Framework 版本有
- OpenMcdf 3.x API：RootStorage.Open() + OpenStream()
