# 2026-06-21 工作日志

## 应用克隆 bug 修复
- **问题**：克隆后的应用不显示在列表中
- **根因**：`Clone` 方法没设 `DeleteMark = 0`（int? 默认 null），列表查询 `DeleteMark != 1` 时 null 被排除
- **修复**：加 `DeleteMark = 0` + `IgnoreColumns(ignoreNullColumn: true)` + `ProviderId`/`ModelId` 空值兜底
- **教训**：SqlSugar `int?` 字段默认 null，必须显式设值

## Agent 对话历史 steps 保存与加载
- **问题**：切换历史对话时，Agent 执行步骤不显示
- **根因**：steps 没有保存到数据库
- **修复**：
  - `ai_message` 表新增 `f_steps` 字段（text, nullable）
  - `SaveChatInput` 加 `steps` 字段
  - `AiConversationService.SaveChat` 保存 steps，`GetDetail` 返回 steps
  - `AiMessageOutput` 加 `steps` 字段
  - 前端 `saveChat()` 传 `steps`（JSON.stringify），`loadMessages()` 解析 `steps`（JSON.parse）
- **SQL**：`ALTER TABLE ai_message ADD COLUMN IF NOT EXISTS f_steps text;`

## Agent steps 工具名不显示
- **问题**：步骤卡片显示但工具名称为空
- **根因**：后端 `AgentStep` 用 PascalCase（`ToolName`），前端用 camelCase（`toolName`）
- **修复**：前端模板兼容两种格式 `step.toolName || step.ToolName`

## Skill 版本管理
- **问题**：数据库有版本记录，但 UI 完全不显示版本
- **修复**：
  - `ai_skill` 表新增 `f_version` 字段（varchar(50)）
  - `AiSkillEntity` + `AiSkillDto` 加 `version` 字段
  - `AiSkillService.Options` 返回 version
  - 列表/详情页显示紫色版本标签
  - 应用选择技能时显示版本号（如 `PDF文字提取 (v1.0.0)`）
  - 导入时自动保存版本
- **SQL**：`ALTER TABLE ai_skill ADD COLUMN IF NOT EXISTS f_version varchar(50);`

## 脚本工具跨应用可用性
- **确认**：脚本工具是全局的，安装到任何应用都能用
- Skill 安装时合并 `toolIds` 到应用，工具 ID 指向 `ai_tool` 全局表
- 脚本文件存储在 `wwwroot/skills/{skillId}/scripts/`，不绑定特定应用
- 如果某应用调用失败，检查：1) 应用 toolIds 是否包含该工具 2) 脚本文件是否存在 3) 模型是否支持 function calling

## Skill 存储路径重构
- **路径**：从 wwwroot/skills/ 改为 KeyVariable.SystemPath + AiSkill/
- 实际路径：D:\xrrb\work_daily_report_resource\AiSkill\{zipName}/
- ImportZip 用 zip 文件名做目录名（如 pdf-image-text-extractor-1.0.0/）
- 保留完整目录结构（SKILL.md、scripts/、references/、assets/）
- ExportZip 打包整个技能目录，文件名 = 目录名.zip

- 旧技能 fallback：先查 SystemPath，不存在再查 wwwroot
- 旧工具 URL 批量更新 SQL：UPDATE ai_tool SET f_url = REPLACE(f_url, '...\wwwroot\skills\', '...\AiSkill\')
